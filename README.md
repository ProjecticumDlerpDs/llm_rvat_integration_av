# llm_rvat_integration_av
Benchmarking a prototype that connects a large language model to a database generated by rvat, through querychat.

## Information
This project attempts to simplify retrieving information from RVAT's database (gene database or gdb) by using a local LLM-model that creates SQL-queries from natural language input from the user. To connect RVAT's database to a local LLM-model the R-package querychat will be used, along with a local LLM model through  Ollama. The goal is to benchmark the built querychat app with 17 benchmark questions. The project contains a benchmark method based on SPIDER. It also makes logging of the chat history possible with a 'Save Chat History' button in the Shiny app. 
Instructions for a quickstart are at the end of the README.

## Research questions
To achieve this goal the following questions were asked.  

### Main question  
To what extent is it possible to generate reliable and accurate SQL queries for an RVAT database (gdb) via natural language prompts when using QueryChat with Ollama as the client?

#### Sub-questions  
The sub-questions are divided into questions for exploring Ollama and the used R-packages, building a pipeline for the desired Querychat app (prototype), and the performance of the LLM models used within the prototype (benchmarking).

##### Exploring Ollama and R packages

1. How does Ollama work within an R environment?

2. How does Querychat work with Ollama as a client?

3. What requirements must a database meet to be compatible with Querychat?

4. How is the RVAT database generated and how is it customizable?

##### Pipeline prototype
5. How can Querychat be connected to the RVAT database?

6. How can the chat history be saved for analysis?

##### Benchmarking large language models within Ollama
7. Which LLM model within Ollama is most suitable for generating SQL queries within Querychat?

8. To what extent can the benchmark questions be accurately and reliably answered with at least a yield exact semantics(YES) score (using this model?

## Quick start
If you meet the requirements above, follow these steps for a quick start to launch the querychat app.  
1. Clone the Github repository  
2. Make a corresponding R project in Rstudio(Posit)  
3. Run renv::restore() in console  
4. If not installed already, install Ollama locally: https://ollama.com/.
Download clients you want to use that have the capability **tools**, best results up to this point are with qwen3\:8b: https://ollama.com/search?c=tools  
5. Select the ollama model by following and running "prototype/1_client_setup.R"  
6. Setup gdb database to include 'varInfo_synthetic' table by following and running "prototype/2_gdb_setup.R"  
7. The basic system prompt of querychat is used along with a data description and extra instructions added in markdown files. There's also a custom greeting with benchmark questions. If you want to change the prompts or greeting, do so before going to next step. Paths and information are found below*.  
8. Setup and launch shinyapp through querychat by following and running "prototype/3_querychat_app_setup.R"  

#### * Path to greeting and prompts
**Path greeting:** *"prototype/prompts/greeting.md"*  
More information is found here: https://posit-dev.github.io/querychat/r/articles/greet.html  
  
**Path data description:** *"prototype/prompts/data_desctiption.md"*  
**Path extra instructions:** *"prototype/prompts/extra_instructions.md"*  
More information is found here: https://posit-dev.github.io/querychat/r/articles/context.html
